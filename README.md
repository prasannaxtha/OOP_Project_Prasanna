# Supermarket Billing System

## Description

The Supermarket Billing System is a Python console application developed using Object-Oriented Programming concepts. It allows users to add products, view products, add products to a shopping cart, and generate bills with automatic discount and VAT calculations.

## Features

- Add Product
- View Products
- Shopping Cart
- Bill Generation
- JSON Data Storage
- Exception Handling

## Technologies Used

- Python
- JSON
- Object-Oriented Programming

## OOP Concepts Used

- Abstract Base Class (ABC)
- Inheritance
- Encapsulation
- Classes and Objects

## How to Run

```bash
python main.py
```
